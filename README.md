# Selenium Automation Scripts – Java

This repository contains end-to-end UI automation test scripts written in **Java** using **Selenium WebDriver**. The test cases cover core user journeys for sample e-commerce websites, including login, registration, product search, and profile management.

## 📁 Project Structure

| File / Class Name         | Description                                           |
|---------------------------|-------------------------------------------------------|
| `LoginPage.java`          | Page Object Model (POM) for the login functionality   |
| `LoginTest.java`          | Test class for login scenarios                        |
| `RegisterPage.java`       | POM for user registration                             |
| `RegisterTest.java`       | Test class for registration                          |
| `CreateAccPage.java`      | Handles account creation logic |
| `SearchProductPage.java`  | POM for product search functionality                 |
| `SearchProductTest.java`  | Test class for searching products                    |
| `MyProfilePage.java`      | POM for user profile-related actions                 |
| `Tests.java`              | Centralized test runner  |

## ✅ Features Covered

- User registration
- Login/logout
- Search for products
- View and update profile
- Page Object Model (POM) design
- Test automation using Selenium WebDriver

## 🛠 Technologies Used

- **Java**
- **Selenium WebDriver**
- **TestNG**
- **Eclipse**
